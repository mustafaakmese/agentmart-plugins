# AgentMart plugin for Codex

This folder is the copy of the AgentMart plugin that Codex installs, through .agents/plugins/marketplace.json: the Codex
manifest, the MCP server and the two skills, without the root plugin.json. So Codex offers every tool of the server.

It is generated from the root of this repository; change the files there, not here. How to install it and sign in:
the README at the root of this repository.
